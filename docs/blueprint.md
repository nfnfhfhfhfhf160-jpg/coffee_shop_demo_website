# **App Name**: Aura Brews & Bites

## Core Features:

- Hero Section with Glassmorphism Design: An captivating hero section with the brand name, tagline, and a premium glassmorphism effect to introduce the cafe's aesthetic.
- Live Operating Status Display: Dynamically displays the cafe's open/closed status with a pulsing green indicator for 'Open Now!', enhancing user engagement.
- Interactive Categorized Menu: An elegantly designed, interactive menu with categorized tabs (Coffee, Juices, Desserts) featuring subtle hover effects and detailed item displays.
- AI-powered Menu Assistant Tool: A generative AI tool that suggests menu items based on dynamic factors such as the current time of day or general weather conditions, providing personalized recommendations.
- Floating Action Button for Reservations: A sticky floating action button providing quick access to WhatsApp messaging for inquiries or direct reservation bookings.
- Immersive Image Gallery: A gallery showcasing high-quality, real Unsplash images of the cafe's delectable offerings and inviting ambiance, utilizing lazy loading for optimal performance.
- Subtle Animations and Micro-interactions: Incorporates smooth scrolling, fade-in effects for content, and tasteful micro-interactions on UI elements to provide a 'hyper-premium' user experience.

## Style Guidelines:

- The visual design will adopt a sophisticated dark theme, evoking 'Aura,' 'Magic,' and 'Premium Cafe Vibes'. The primary color will be a warm, inviting medium purple (#A18CD1), serving as a luminous accent against darker elements. The background will be a deep, desaturated purple-grey (#26202D), providing an elegant backdrop that enhances the 'glassmorphism' effect. A vibrant blue (#5499DE) will be used as an accent, adding a contemporary pop for interactive elements.
- For a blend of modernity and clarity, 'Poppins' (sans-serif) will be used for headlines, conveying an avant-garde and precise feel. 'Inter' (sans-serif) will be employed for body text, ensuring excellent readability and a neutral, objective aesthetic that complements the overall premium design.
- Sleek, minimalist line icons will be used throughout the application to maintain a clean, ultra-modern, and premium feel consistent with the 'glassmorphism' aesthetic.
- The layout will feature full-width, clean, and spacious sections, designed to be highly responsive and mobile-first. Emphasis will be placed on visual hierarchy, ensuring a fluid and intuitive browsing experience with ample negative space to highlight content.
- Animations will be subtle and purpose-driven, including smooth scrolling transitions between sections, gentle fade-in effects for content on load, and elegant hover effects for interactive elements to provide 'cool micro-interactions' without distracting from the content.
